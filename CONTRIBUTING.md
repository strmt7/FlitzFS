# Contributing to FlitzFS

Start with the [developer guide](docs/development/README.md).
FlitzFS is experimental; the owner controls release and publication.

For a bug report, include the build or commit, exact action, expected result,
observed result and a small reproducible input. Preserve original data and
remove private information from reports.

Before changing a component, read its canonical contract through the
[reference index](docs/reference/README.md), preserve compatibility and recovery
requirements, and select checks appropriate to the behavior.
AI agents must follow [AGENTS.md](AGENTS.md) and the required skills.

Documentation changes follow the [authoring conventions](docs/development/documentation.md).
Keep user-facing instructions separate from implementation details and
source-specific qualification records.
