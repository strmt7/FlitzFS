# FlitzFS branding

The red layered F symbol is distinct from FlitzZip's outlined diamond symbol.
The family reference is its vivid red/charcoal palette and clean, bold typography.
This is filesystem branding; it does not imply archive-format affiliation.

The wordmark is typeset with **actual Segoe UI Bold**, the preferred family and
weight in the inspected FlitzZip SVG. It is not image-generated lettering.
The SVGs contain the font's glyph outlines, so rendering does not depend on
installed fonts. No font files are distributed. The AI-assisted symbol remains
a PNG embedded in the self-contained SVG; the complete mark is not all-vector.
